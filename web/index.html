One gateway session, shared

    
The gateway allows one session per user, so this page avoids opening a second one. It looks in this order:

    
    
      
  1. Desktop Hoppla on this computer (planned). A small local helper would let this page borrow the open session. It is also the only way other programs, such as your normal browser profile or an RDP client, can share a connection. Not available in this preview.
    2. 
      
  2. Another tab of this page. Works in this preview: sign in once, open the page in a second tab, and that tab skips the sign-in.
    3. 
      
  3. A new sign-in, only if neither exists. That session belongs to this page, and only its tabs can use it. The gateway may refuse a desktop Hoppla login while it is open, so use End session first.
